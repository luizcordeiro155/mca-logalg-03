## Linguagem utilizada

Os exercícios foram implementados em **Java**, adaptando os elementos pedidos no Portugol para os equivalentes da linguagem:

- `logico` -> `boolean`
- `nao` -> `!`
- `e` -> `&&`
- estrutura condicional `se` -> `if`

## Exercícios

1. **O Escudo do Cavaleiro** - verifica se o escudo está inativo e informa o dano.
2. **Alarme do Cofre** - lê o estado do cofre e dispara o alerta quando não está trancado.
3. **Sensor da Estufa de Plantas** - liga os irrigadores quando o solo não está úmido.
4. **Validação de Termos de Uso** - bloqueia o acesso quando os termos não foram aceitos.
5. **Controle de Farol de Carro** - alerta quando é noite e o farol está desligado.
6. **Verificação de Conexão com a Internet** - ativa o modo offline quando não há conexão.
7. **Painel de Combustível da Nave** - autoriza a decolagem quando o tanque não está na reserva.
8. **Portão Eletrônico Residencial** - abre o portão quando nenhum obstáculo é detectado.
